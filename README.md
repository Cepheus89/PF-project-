Currently the game possesses a temporary boss sprite and some temporary projectile sprites. Functions such as the menu, sound control and start game have been added. Controls are currently WASD based. The first phase has been integrated with the projectile phase with the second and third phase in process. Currently it loops the first phase. Any dimensions and sprites are subject to change according to the collaborators (save for the TA) wishes. The first phase currently includes a crescent type projectiles, a horizontal projectiles, a pinwheel projectiles and the homing darts projectiles. These types are subject to change in accordance to the collaborators wishes once again.
